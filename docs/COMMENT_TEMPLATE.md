# Suggested comment to share after publication

For anyone using the discontinued **Nexus Mods App on Linux** with Cyberpunk 2077 who is getting `Version: Unknown` or the `Cannot backup ... exceeds maximum of 5 GB` deployment error after a Steam update: I built an unofficial helper that regenerates the game's hash database from your own installed Steam manifest and SHA-1-verified game files, without changing the AppImage or disabling Nexus's backup protection.

It worked for my Cyberpunk 2077 **2.5** Steam installation (build **26161058**), and I published the scripts and rollback instructions here: **https://github.com/YOUR-USERNAME/cyberpunk-nexus-app-hashfix**.

This is an **experimental, Steam/Linux-only** workaround; please read the README and make backups first. It doesn't update incompatible mods—my remaining launch crash was an outdated **Mod Settings** plugin. Feedback and test reports are welcome.
