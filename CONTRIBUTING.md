# Contributing

Thank you for helping keep the Linux Cyberpunk modding community functional.

The highest-value help is **a reproducible test report**: Linux distro, Steam flavor, Nexus Mods App version, actual Cyberpunk version/build, manifest ID, script stage and relevant sanitized log. Never attach games, full AppData backups, private file paths, tokens, or copyrighted archives.

Please open an issue before proposing changes that edit installed game files, disable Nexus's 5 GB safety guard, or support new app/depot combinations. Keep any new version or store support opt-in. Add unit tests for metadata parsing and safety checks.
